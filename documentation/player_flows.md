# Player flows: create/select Character, start Quest

## Scope
Définir le parcours joueur minimal du MVP.

## Parcours
- Créer un personnage.
- Sélectionner un personnage existant.
- Démarrer une quête.
- Enchaîner les étapes.
- Gagner de l'XP.

## Critères d'acceptation
- Le flux est testable sans UI finale.
- Les cas heureux et erreurs principales sont couverts.
